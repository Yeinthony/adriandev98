## Descripción detallada

Panel administrativo para Isipay, una plataforma fintech de criptomonedas. El panel permite gestionar tasas de cambio, administrar usuarios, configurar parámetros del sistema y monitorear transacciones en tiempo real. El proyecto implicó una migración completa desde Next.js a Vue 3.

## Mi rol e impacto

Lideré la migración del panel administrativo de Next.js a Vue 3, reescribiendo componentes, lógica de negocio y la capa de estado. Mantuve la paridad funcional mientras mejoraba la experiencia de desarrollo y el rendimiento.

## Retos técnicos

La migración entre frameworks fue el reto principal. Fue necesario mapear conceptos de React a Vue, reestructurar la gestión de estado y adaptar las integraciones con APIs existentes sin interrumpir el servicio.

Las configuraciones financieras requieren validaciones extremadamente estrictas, ya que un error en una tasa de cambio puede tener consecuencias significativas.

## Aprendizajes

Este proyecto me enseñó estrategias efectivas de migración entre frameworks, la importancia de las validaciones robustas en productos financieros y cómo diseñar interfaces administrativas que minimicen el error humano.

## Mejoras y optimizaciones

- Validaciones en múltiples niveles para configuraciones financieras
- Historial de cambios en configuraciones críticas para auditoría
- Mejora en tiempos de carga y rendimiento general tras la migración
